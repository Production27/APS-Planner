# TeamSync

Construction production scheduling tool: Gantt chart, Job Manager, a
Trello-style Board, Calendar, and a Home dashboard, built for a small
team working on a fixed pair of projects. User-facing product name is
**TeamSync**. A few internal identifiers still use the old `aps-planner` / `APS-Planner`
name on purpose, because renaming them would break deployed data or infrastructure
(the GitHub repo and Pages URL, the staging Worker name and URL, the R2 backup
bucket, and the `aps-planner:*` localStorage keys).

## How it's built

Plain HTML/CSS/JS shipped as static files — no framework, no server-side
rendering.

- **`index.html`** — the page's markup and styling, plus a small amount
  of cross-script `var` data declarations and boot glue that genuinely
  needs to live there. Almost all of the app's actual logic lives in
  `src/` below.
- **`src/`** — TypeScript modules for the app's logic, compiled and
  bundled into a single script the page loads:
  - `src/views/` — Board, Calendar, Gantt, Checklist, Job Manager, Home
    dashboard
  - `src/app/` — cross-cutting app concerns: project switching, the
    admin/user-management panel, backups, maintenance mode, onboarding,
    activity log, theming, settings
  - `src/auth/` — login, session/token handling, permission tiers
  - `src/sync/` — real-time sync with the backend (connection handling,
    inbound/outbound messages, presence)
  - `src/core/` — shared data types and models
  - `src/utils/` — small shared helpers
  - `src/main.ts` — the entry point; imports everything above and
    attaches it to `window` so `index.html` can call it
- **`worker/`** — the backend: a Cloudflare Durable Object that holds
  each project's live state and pushes updates to connected clients over
  WebSockets. Deployed independently of the frontend (see below).
- **`dist/`** — the built output of `src/` (`dist/app.bundle.js`).
  Generated by the build step, not committed to git.

## Building and running

```
npm install
npm run build          # bundles src/ into dist/app.bundle.js
```

Then open `index.html` in a browser (or serve the repo root with any
static file server).

## Tests

```
npm run typecheck         # type-check src/
npm run typecheck:worker  # type-check worker/src/
npm test                  # Playwright suite against index.html
npm run test:worker       # worker unit tests (node:test)
```

## Deployment

Frontend and backend deploy separately.

- **Frontend**: GitHub Actions (`.github/workflows/deploy.yml`) builds
  and deploys `index.html`, `dist/`, `assets/`, and `version.txt` to
  GitHub Pages automatically on every push to `main`, after the test job
  passes.
- **Backend**: the Cloudflare Worker in `worker/` is deployed manually
  with `npx wrangler deploy` from inside `worker/` — a separate step,
  not run by CI.
